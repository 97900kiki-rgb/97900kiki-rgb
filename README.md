# AI 패션 코디네이터 (AI CODI)

"뭐 입지?" 고민, 이제 끝 — 나만의 AI 스타일리스트를 소개하는 원페이지 랜딩 웹앱입니다.
업로드해주신 PPTX(`나만의 AI코디네이터`) 슬라이드 내용을 기반으로 제작했습니다.

## 🎯 프로젝트 목표
- AI 패션 코디네이터 서비스의 시장 기회, 문제 정의, 비전, 솔루션을 매력적으로 소개하는 랜딩 페이지 제공
- 내 손안에 AI 코디네이터가 있다면.. 절약적이고 경제적인 소비 생활과 분석적 트렌디한 정보를 줄 수 있다면.. 하는 마음에서 아이디어를 실물로 실행해 보았습니다.
## ✅ 현재 완성된 기능
- 메인 섹션을 클릭하면 다른 창으로 연결되는 서비스 창.
- 나만의 AI 비서를 동영상으로 만듬.
- 코디 등록하면 이미지에서 추출한 컬러를 볼 수 있도록 보완.
- 잘 못 입력시 수정할 수 있도록 보완.
- 불특정 다수의 의견을 반영한 별점 서비스 추가 생성.
### 1. 랜딩 소개 섹션
1. **헤더/네비게이션** — 고정 헤더, 스크롤 시 배경 블러, 모바일 햄버거 메뉴
2. **히어로 섹션** — PPTX 표지 카피, CTA 버튼, 생성 이미지, 플로팅 정보 카드
3. **시장 기회** — 4개 통계 카드
4. **문제 정의** — 3가지 핵심 문제 카드
5. **비전 & 솔루션** — 서비스 가치와 4단계 프로세스 소개
6. **옷장 스캔 쇼케이스** — AI가 옷장 아이템을 인식하는 모습을 소개하는 섹션
7. **최종 CTA** — 서비스 소개 마무리 및 행동 유도 섹션

### 2. 공통
- 반응형 디자인 (데스크톱/모바일 대응), 스크롤 reveal 애니메이션, 다크 그라데이션 테마

> 🗑️ **기능 삭제 안내**:
> - 기존에 있던 "AI 코디 체험" 데모 섹션(상황/퍼스널컬러/날씨 선택 → 즉석 코디 추천 + 쇼윈도 마네킹 DP)은 사용자 요청에 따라 전체 삭제되었습니다.
> - 코디 갤러리 등록/수정 폼과 상세 모달에 있던 **쇼윈도 마네킹 디스플레이 기능**도 이어서 삭제되었습니다.
> - 그리고 이번 작업에서 **코디 갤러리 & 별점 서비스 전체**(코디 목록/필터/정렬/통계, 코디 상세 모달, 별점·리뷰 등록, 내 코디 등록/수정/삭제, 이미지 업로드 및 자동 무드보드 생성 기능 포함)가 사용자 요청에 따라 완전히 삭제되었습니다. 관련 HTML 마크업(`#gallery`, `#outfit-modal`, `#add-modal`), JavaScript 파일(`js/gallery.js`), CSS 스타일이 모두 제거되었고, 헤더/모바일 메뉴/히어로/최종 CTA에 있던 "코디 갤러리" 관련 링크는 모두 `#solution`(솔루션 섹션)으로 연결되도록 정리했습니다.
> - 이제 사이트는 순수 소개용 랜딩 페이지로만 구성되어 있으며, 사용자가 데이터를 등록/조회하는 기능은 없습니다.

## 🔗 페이지 구성 (단일 페이지, 앵커 이동)
- `/index.html` — 메인 페이지
  - `#hero` 히어로
  - `#market` 시장 기회
  - `#problem` 문제
  - `#vision` 비전
  - `#solution` 솔루션
  - `#cta` 최종 CTA

> 별도의 서버 API 호출이나 데이터 조작 기능은 없습니다. 페이지는 순수 정적 소개 콘텐츠로만 구성되어 있습니다.

## 🗂 데이터 모델
- 현재 UI에서 사용하는 데이터 테이블은 없습니다.
- 과거 코디 갤러리 기능에서 사용하던 `outfits`, `ratings` 테이블 스키마는 참고용으로 남아있을 수 있으나, 어떤 화면에서도 더 이상 참조되지 않는 미사용 상태입니다. 완전히 삭제를 원하시면 말씀해주세요.
