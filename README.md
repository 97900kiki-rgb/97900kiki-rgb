# AI 패션 코디네이터

AI 패션 코디네이터는 사용자의 스타일 고민을 줄이기 위해 디자인된 단일 페이지 랜딩 웹앱입니다.
핵심 목적은 패션 서비스의 문제를 시각적으로 설명하고, AI 스타일리스트 이미지를 통해 브랜드 메시지를 전달하는 것입니다.

## 프로젝트 구성
- `index.html`: 메인 랜딩 페이지
- `chat.html`: AI 대화형 소개 페이지
- `style-guide.html`: 5분 스타일 가이드 페이지
- `css/style.css`: 전체 스타일
- `js/main.js`: 인터랙션 스크립트
- `images/`: 메인 이미지, 아이콘, 일러스트
- `videos/`: 비디오 콘텐츠

## 실행 방법
브라우저에서 바로 열어도 동작합니다.

1. 프로젝트 폴더를 열기
2. `index.html` 또는 `chat.html` 파일을 브라우저에서 실행
3. `chat.html`은 Gemini API 키를 입력하면 실시간 스타일 상담을 사용할 수 있습니다
4. 로컬 환경에서는 정적 파일로 바로 확인 가능

## 배포
http://localhost:8000/index.html

### GitHub Pages 배포 방법
1. GitHub 저장소에 이 프로젝트를 업로드합니다.
2. 저장소 설정에서 Pages를 열고, Source를 `Deploy from a branch`로 선택합니다.
3. 브랜치는 `main` 또는 `master`를 선택하고, 폴더는 `/root`를 선택합니다.
4. 사이트가 생성되면 제공되는 URL에서 확인할 수 있습니다.
5. 브라우저에서 `chat.html`을 열면 Gemini API 키를 입력해 실시간 스타일 상담을 사용할 수 있습니다.

### 주의사항
- 이 프로젝트는 정적 HTML/CSS/JS 구조라서 서버 설치 없이도 동작합니다.
- Gemini API 키는 브라우저의 `localStorage`에만 저장되며 서버에 전송되지 않습니다.
- GitHub Pages는 정적 호스팅이므로 백엔드, 로그인, DB 기능은 별도로 구성해야 합니다.

## 참고
이 프로젝트는 정적 랜딩 페이지 중심으로 구성되어 있으며, 사용자 데이터 저장, 로그인, DB 연동 기능은 포함하지 않습니다.
